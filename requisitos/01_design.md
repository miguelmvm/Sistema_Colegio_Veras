# REQUISITOS DE DESIGN E UI/UX (Colégio Veras)
- Estética Premium: O design deve ser moderno, limpo e responsivo.
- Cores Institucionais: Azul profundo (#0d2b56), cinza ardósia, com realces dourados ou verdes para sucesso.
- Componentes: Usar cards com soft shadows (sombras suaves), bordas arredondadas (border-radius: 16px).
- Interação: Efeitos de 'hover' suaves e transições em modais/abas (display: none para block com fadeIn).
- Regra de Ouro: Nunca quebre a navegação por abas. Abas inativas devem estar com display: none.
